# صيدة — موقع تجميع عروض المتاجر (مصر والوطن العربي)

موقع ثابت (Static) بيعرض عروض وكوبونات من أشهر المتاجر والتطبيقات، وفيه قائمة بـ **64 منصة** (مصر، السعودية، الإمارات، الكويت، المغرب + متاجر عالمية بتشحن للوطن العربي). المستخدم يختار الدولة والمتجر ويكتب اسم المنتج، فيتفتح له البحث جوه المتجر ده برابط الأفلييت بتاعك.

> الاسم «صيدة» والإيميل والروابط كلها قيم مؤقتة — غيّرها من `config.json`.

## 1) محتويات المشروع

| الملف | وظيفته |
|---|---|
| `index.html` + `css/style.css` + `js/app.js` | الموقع نفسه (بدون أي مكتبات، سريع على الموبايل) |
| `config.json` | **أهم ملف**: اسم الموقع، روابط التواصل، الإعلانات، ومعرّفات الأفلييت |
| `platforms.json` | قائمة المنصات وروابط البحث بتاعتها |
| `data/deals.json` | العروض اللي بتظهر في الموقع (حاليًا بيانات **تجريبية**) |
| `scraper/fetch_deals.py` | بيجمع العروض من المصادر ويكتب `deals.json` |
| `scraper/post_telegram.py` | بينشر العروض الجديدة على قناة تيليجرام |
| `.github/workflows/update-deals.yml` | بيشغّل الاتنين تلقائيًا كل 3 ساعات |
| `legal.html` | الخصوصية + الإفصاح عن الأفلييت + الشروط (مطلوبة للأفلييت والإعلانات) |

## 2) تشغيل محلي

```bash
cd deals-hub
python3 -m http.server 8000
# افتح http://localhost:8000
```
لازم سيرفر محلي (مش دبل كليك على الملف) عشان المتصفح يقرأ ملفات JSON.

## 3) النشر

1. ارفع المجلد كله على مستودع GitHub.
2. اربط المستودع بـ **Cloudflare Pages** أو **Netlify** (من غير Build command، والمجلد الأساسي `/`).
3. من تاب **Actions** في GitHub شغّل «تحديث العروض» يدويًا أول مرة (Run workflow).

> **مهم قبل ما تختار الاستضافة:** حسب علمي، خطة Vercel المجانية (Hobby) للاستخدام غير التجاري، وGitHub Pages شروطها بتمنع المواقع اللي هدفها الأساسي المعاملات التجارية. موقع بيكسب عمولات يعتبر تجاري، فراجع شروط أي منصة قبل ما تعتمد عليها. Cloudflare Pages وNetlify أنسب للمشروع ده — وبرضه راجع الشروط الحالية.

## 4) الإعدادات (`config.json`)

- `brand`: اسم الموقع والإيموجي.
- `site_url`: رابط موقعك بعد النشر (بيتولّد منه `sitemap.xml` تلقائيًا).
- `social.telegram` / `social.whatsapp`: روابط قناتك. لو فاضية، قسم الاشتراك بيختفي.
- `contact_email`: إيميل التواصل (بيظهر في الفوتر وصفحة الخصوصية).
- `affiliates`: معرّفات الأفلييت (القسم الجاي).

## 5) الأفلييت (مصدر الأرباح)

كل منصة في `config.json → affiliates` ليها طريقة من اتنين:

- **`param`** (أمازون): بيضيف `tag=معرفك` للرابط.
  ```json
  "amazon-eg": { "mode": "param", "param": "tag", "value": "yourtag-21" }
  ```
- **`template`** (الشبكات): بتحط رابط الـ Deep Link من لوحة الشبكة، ومكان رابط المنتج `{url}`.
  ```json
  "jumia-eg": { "mode": "template", "template": "https://ad.admitad.com/g/XXXXXX/?ulp={url}" }
  ```
  (`{url}` = الرابط مشفّر، `{url_raw}` = الرابط زي ما هو.)

أي منصة معرّفها فاضي بيطلع رابطها عادي من غير عمولة.

| المنصة | التسجيل |
|---|---|
| أمازون مصر / السعودية / الإمارات | `affiliate-program.amazon.eg` / `.sa` / `.ae` — كل دولة حساب وtag منفصل. برنامج مصر كان بالموافقة لما اتفتح، فاتأكد من حالته |
| جوميا | `jumia.com.eg/affiliate-program` (وبعض الدول ظاهرة كمان على شبكات زي Admitad) |
| نون | برنامج نون للشركاء أو عن طريق شبكات (CJ، FlexOffers وغيرها) — اتأكد من المتاح لبلدك |
| علي إكسبرس، تيمو، شي إن، بوكينج، أجودا، يوديمي، هوستنجر… | كلها ليها برامج أفلييت مجانية على مواقعها أو شبكات (Admitad / Awin / Impact / CJ) |

الشروط والعمولات بتتغير — اتأكد منها من لوحة كل برنامج.

### ملاحظات أمازون (مهمة)
- لازم يكون موجود في الموقع وفي الفوتر جملة: *As an Amazon Associate we earn from qualifying purchases* (موجودة).
- **قناة تيليجرام لازم تتسجل كمصدر ترافيك في حساب أمازون** قبل ما تنشر عليها روابط أمازون.
- أمازون بتشدد على أن الأسعار المعروضة تكون محدّثة. الأسلم لعروض أمازون تستخدم الحقل `badge` («خصم حتى 20%») بدل سعر ثابت.
- واجهة **PA-API القديمة اتقفلت في 15 مايو 2026** وحلّ محلها **Creators API**، وبتحتاج حد أدنى مبيعات (المتداول حوالي 10 مبيعات مؤهلة في آخر 30 يوم — اتأكد من حسابك). يعني في البداية مفيش سحب أسعار تلقائي من أمازون: العروض بتتضاف يدويًا.

## 6) إزاي تضيف العروض

### أ) Google Sheet (الأسهل والأضمن) ✅
1. اعمل Google Sheet واستورد `data/sheet-template.csv` (الأعمدة: `title, platform, url, price, old_price, currency, type, coupon, category, image, badge, expires`).
2. **File → Share → Publish to web** → اختار الورقة وصيغة **CSV** → انسخ الرابط.
3. في GitHub: **Settings → Secrets and variables → Actions → New repository secret** باسم `SHEET_CSV_URL` والقيمة الرابط.
4. أي صف تضيفه بيظهر في الموقع خلال 3 ساعات (أو شغّل الـ workflow يدويًا).

قواعد الصفوف:
- `platform` = معرّف المنصة من `platforms.json` (مثل `amazon-eg`). لو فاضي بيتعرّف تلقائيًا من رابط المتجر.
- `url` = رابط المتجر **الأصلي** (مش رابط أفلييت) — الموقع بيضيف عمولتك تلقائيًا.
- `type` = `deal` أو `coupon` أو `free` (أو خصم/كوبون/مجاني). لو فيه `coupon` بيبقى كوبون تلقائيًا.
- `expires` تاريخ `2026-12-31` — العرض بيختفي لوحده بعده.
- الأرقام العربية والفواصل (١٬٢٩٩) بتتفهم.

### ب) مصادر تانية
في `scraper/sources.json` أمثلة جاهزة (`enabled: false`) لملفات CSV من شبكات الأفلييت، وRSS، وJSON API مع ربط الحقول. فعّل اللي عندك صلاحية عليه.

### ليه مفيش سحب مباشر من أمازون/نون/جوميا؟
سحب صفحاتهم بسكربت غالبًا بيخالف شروط استخدامهم، وبيتحظر بسرعة من عناوين GitHub Actions، وممكن يتسبب في إيقاف حساب الأفلييت. المصادر الرسمية (ملفات الشبكات، الكوبونات، التحديث اليدوي) أضمن وأربح على المدى الطويل.

## 7) بوت تيليجرام

1. من `@BotFather` اعمل بوت وخد التوكن.
2. اعمل قناة وضيف البوت **Admin** فيها.
3. Secrets في GitHub: `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` (مثل `@my_channel`).
4. اختبار بدون إرسال: `python scraper/post_telegram.py --dry-run`

البوت بينشر لحد 5 عروض جديدة في التشغيل، بروابط الأفلييت، ومش بينشر العروض التجريبية ولا الأقدم من 36 ساعة. واتساب مفيش له نشر تلقائي رسمي — انسخ العروض يدويًا لقناة واتساب.

## 8) الإعلانات (غير مزعجة)

- مفيش بوب-أب ولا إعلانات ثابتة فوق المحتوى. فيه 3 أماكن بس: بين المتاجر والعروض، قبل الفوتر، وكارت واحد كل 9 عروض. وكلها عليها كلمة «إعلان».
- بدون إعدادات: بتظهر إعلانات داخلية (دعوة للتيليجرام، «أعلن معنا») من `ads.house`.
- **AdSense**: حط `adsense_client` (مثل `ca-pub-123…`) و`adsense_slots`، وعدّل `ads.txt`. جوجل غالبًا بتطلب دومين خاص وموقع فيه محتوى كفاية قبل الموافقة.

## 9) نقاط لازم تعرفها

- **بيانات `deals.json` الحالية تجريبية** وعليها علامة «تجريبي». أول ما `SHEET_CSV_URL` يشتغل، السكربت بيستبدلها بالكامل.
- **روابط البحث** (`search` في `platforms.json`) كتبتها من معرفتي بأنماط المتاجر ومقدرتش أجربها لايف. جرّب كل متجر مرة. لو نمط اتغير، عدّل السطر؛ والمنصات اللي من غير `search` بيتم البحث فيها عن طريق جوجل داخل موقع المتجر.
- **الدومين**: الدومين المجاني شغّال للبداية، لكن كتير من الشبكات وAdSense بتفضّل دومين خاص (تكلفته بسيطة سنويًا).
- **صور المنتجات**: لو حطيت `image` من موقع متجر، تأكد إن شروطهم بتسمح بعرضها.
- **صفحة `legal.html`** قالب عام وليست استشارة قانونية؛ راجعها حسب بلدك ونشاطك.

## 10) إضافة منصة جديدة
أضف عنصر في `platforms.json → platforms` (`id` فريد، `name`، `en`، `countries`، `category`، `domain`، `home`، و`search` برابط فيه `{q}` مكان كلمة البحث أو `null`). وبعدها ضيف معرّف الأفلييت في `config.json`.
